What is a Kitchen Display System?

A Kitchen Display System (KDS) is a digital order-view system that has replaced handwritten and printed ticket orders. It's used in restaurant kitchens and communicates with the restaurant's Point of Sale (POS).

Most kitchens are hot, loud and chaotic — it's easy for a printed or handwritten ticket to get lost, damaged or rendered illegible. KDS screens communicate with each other to display real-time updates on item / ticket status, keeping communication clear in a busy kitchen.

Changes like ticket merges, recalls, and item / ticket completions are all shared across the KDS environment, so every kitchen station stays up to speed on a ticket from creation to completion.

Ticket views

Shift4's KDS can display tickets in four arrangements — each station picks what fits its workflow.

▦
Column view

Tickets display in columns. Regardless of how many items are on the order, the ticket begins and ends within one column.

▣
Tile view

Tickets display as varying-sized tiles, squeezing each order's items into all the available display space.

≣
List view

Items are arranged in lines and rows below a header line with the ticket info; staff scroll vertically between tickets.

⊞
Grid view

Tickets arranged horizontally in two rows of fixed columns — best for simple tickets with minor item modifications.

Ticket breakdown. Every ticket shows the order type (Dine In / Pickup / Delivery / Bar), table or guest count, ticket number & server name, the clock time and the elapsed timer, then the items with modifiers, allergies, temps and seat numbers (S1, S2…).

Using the KDS day-to-day

✓
Clearing items & orders

Clear by Item — tap items to mark them fulfilled (turn green); when the last is marked, the ticket bumps. Best for prep/line cooks. Clear by Order — tap Complete at the end of the item list (great for expeditors / QSR). Clear All — clears the whole screen (e.g., after a rush) — note: tickets cleared this way are not counted toward KPI metrics.

✓
Filter by order type

Tap a color-coded order-type name in the upper right (Dine In, Delivery, Pickup, Bar) to filter; tap another to build a custom filter; tap ALL to return to the main view. (Order-type colors are set in Lighthouse.)

✓
Group similar items

The Group button merges similar items on screen to save space. It doesn't change the order — it just helps a station view the ticket to streamline fulfillment.

✓
Merge tickets

Tickets from the same order can appear separately (e.g., when items are added after the first send). Long-press the ticket header and select the additional ticket(s) to merge.

✓
Scroll between pages

Swipe the screen or use the scroll controls at the bottom-right to move through pages of tickets.

✓
Recall

Bring back a cleared ticket with Recall / Recall Last from the bottom toolbar.

Settings

Each display has its own settings — so one kitchen can run different rules per station.

  • Refresh data — pull the latest from the POS
  • Clear ticket — choose Clear by Item or Clear by Order
  • Ticket timers — Warning (default 5 min) & Alert (default 10 min) change the status-bar color as time passes
  • Only if all items fulfilled — with Clear by Order, requires every item fulfilled before Complete works
  • Bump Station — broadcasts item/ticket progress to other stations (e.g., a prep KDS broadcasting status to an Expo station)
  • IP address — the display's network address for setup
